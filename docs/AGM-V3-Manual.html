5. Supabase Setup

  1. Go to supabase.com and create a new project (free tier is enough at launch).
  2. In your Supabase project, go to SQL Editor and paste the contents of supabase/migrations/001_initial_schema.sql. Run it.
  3. Enable Google OAuth in Authentication → Providers. Add your Google OAuth credentials.
  4. Under Authentication → URL Configuration, add your site URL and redirect URLs.
  5. Go to Settings → API. Copy your Project URL, Anon Key, and Service Role Key.
  6. Enable the pgvector extension in Database → Extensions for semantic sermon search.
Tip: The schema includes Row Level Security on every table. Non-admin users can only see and modify their own data. Admins are controlled by the role field in profiles.

7. Payment Setup

PayPal

  1. Go to developer.paypal.com.
  2. Create a new app in the Developer Dashboard.
  3. Copy the Client ID and Secret.
  4. Test in Sandbox mode first, then switch to Live when ready.
  5. Set webhook URL: https://yourdomain.com/api/webhooks/payments
  6. Subscribe to event: PAYMENT.CAPTURE.COMPLETED

Flutterwave (African Payments)

  1. Go to dashboard.flutterwave.com and create an account.
  2. Under Settings → API, get your Public Key and Secret Key.
  3. Add the Flutterwave inline script to your HTML head (or use next/script).
  4. Set webhook URL: https://yourdomain.com/api/webhooks/payments
  5. Supports: MTN Mobile Money, Orange Money, Visa/Mastercard, bank transfer across 30+ African countries.
Note for Cameroon: Flutterwave supports XAF (CFA Franc) and USD. Always set currency to USD for consistency with PayPal. Members in Cameroon can pay via MTN MoMo or Orange Money through Flutterwave.

9. Email Setup (Resend)

  1. Create account at resend.com.
  2. Verify your sending domain (agm.church) by adding DNS records.
  3. Create an API key and add it to RESEND_API_KEY.
  4. Free tier: 3,000 emails/day, 100/month on the free plan — enough for early stage.
  5. Update the from address in /api/admin/broadcast/route.ts to match your verified domain.

10. Deploy to Vercel

1
Push the project to a GitHub repository.
2
Go to vercel.com → New Project → Import from GitHub.
3
Add all environment variables from .env.example in the Vercel dashboard under Settings → Environment Variables.
4
Set Root Directory to the project root. Framework Preset: Next.js. Click Deploy.
5
Add your custom domain in Vercel → Settings → Domains. Point DNS to Vercel's nameservers.
6
In Supabase → Authentication → URL Configuration, update Site URL and Redirect URLs to your production domain.

11. Admin Setup

After deploying, make yourself a super admin:

-- Run in Supabase SQL Editor:
UPDATE public.profiles
SET role = 'super_admin'
WHERE email = 'your-email@example.com';

Then visit https://yourdomain.com/admin to access the full admin panel.

Admin Capabilities

  • View all members, change tiers, manage roles
  • Upload and publish sermons with AI-generated descriptions
  • Send email broadcasts to all or specific tier members
  • View analytics — revenue, growth, member distribution
  • Manage affiliates and approve payouts
  • Control all site settings and feature flags

13. Affiliate System

  • Available exclusively to Kingdom Builder tier members ($49/mo)
  • Each member gets a unique referral code (auto-generated on signup)
  • Referral links: https://agm.church/register?ref=YOURCODE
  • Commission: 30% of every subscription payment for referred members
  • Payouts: Monthly via PayPal or Payoneer — manually approved via admin panel
  • Dashboard: Real-time referral tracking, commission totals, pending payouts
